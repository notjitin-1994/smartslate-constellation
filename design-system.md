# 🌌 Constellation Orchestrator: "Prism Architect" Design System

## 🎨 Visual Identity
A high-fidelity, technical aesthetic focused on depth, precision, and glassmorphism.

### Core Color Palette
- **Background:** `#020617` (Deep Obsidian)
- **Primary Accent:** `#A7DADB` (Prismatic Teal) - Used for structural borders and status glows.
- **Action CTA:** `#4F46E5` (Indigo) - Reserved for active execution triggers.
- **Glass Fill:** `rgba(255, 255, 255, 0.02)`
- **Glass Border:** `1px solid rgba(167, 218, 219, 0.1)`

## 📐 Structural Rules
1. **Refined Sizing:** Typography and icons use a "Small & Sharp" philosophy (10px-13px for most data labels).
2. **Glassmorphism:** All panels use `backdrop-blur-md` or `backdrop-blur-3xl`.
3. **Prismatic Depth:** Use radial gradients with low opacity (5%) for subtle "light leaks" in corners.
4. **Sharp Geometry:** Precision 12px-24px radii; avoid organic or bubbly shapes.

## 🧩 Component Specifications
- **Agent Progress:** Ultra-thin 4px bars with Teal active states.
- **Bento Canvas:** Asymmetric grid layout for narration, visuals, and logic.
- **Verification Layer:** High-contrast Markdown rendering within a blurred obsidian modal.
